# AI 比价雷达

卡网 AI 订阅**只读比价**面板：把多个公开报价源聚合到一个本地面板里，搜索、筛选、直达原始购买链接。**本地运行、只读采集、不参与任何交易**。

![AI 比价雷达](icon.svg)

## 功能

- **全网报价搜索**：按关键词（如 `gpt`、`claude 质保`）在聚合报价里搜索。
- **四路筛选**：数据来源（可用源 / 全部）、库存口径（有货 / 缺货 / 全部含未知）、发卡平台（链动小铺 / 自建站 / 云猫寄售等）、商品交付类型（成品号 / 代充 / 卡密 / 车位等）。
- **统计栏**：主要报价数、来源标记数、当前结果最低价、数据源成功数。
- **报价卡片**：平台徽标、来源、商品标题、价格、店铺、观察时间，点击「查看原始报价」直达商家页面核对。
- **去重口径**：同一商品以「平台 + 店铺标识 + 商品标识」为键聚合，实时直抓行优先于聚合行，报价行不重复计数。
- **数据来源与口径**：面板内置一页说明，写明每个源的抓取方式、授权情况与局限。

## 数据来源

| 来源 | 方式 | 说明 |
|---|---|---|
| BiWu.Ai（biwu.ai） | 官方只读快照 feed `/price-radar/latest.json` → 不可变快照 | 无需鉴权；官方 API 文档（`/price-radar-api.md`）明确供 agent / 脚本读取，支持 ETag 缓存；按约 5 分钟节奏更新 |
| AI价网（aiprice.club） | 解析公开类目页表格 | 数据遵循 CC BY 4.0（署名「AI价网 (http://aiprice.club)」）；整页抓取频率限制在分钟级 |
| 链动小铺（wzyp.cn） | 经上述聚合源覆盖（BiWu 快照大量包含 wzyp.cn 报价） | 不直接抓取其页面 |
| 云猫寄售（catfk.com） | 第一版未直连 | 站点为客户端渲染、无公开只读接口；其报价在 BiWu/AI价网 中有聚合覆盖 |

## 隐私与边界

- 采集请求从**本机宿主进程**发出，不经过任何第三方服务器；结果只保存在内存缓存（默认 5 分钟 TTL）。
- 面板不写入会话日志，不影响模型上下文。
- 所有价格与库存以商家页面为准；本面板只做信息聚合与导航。
