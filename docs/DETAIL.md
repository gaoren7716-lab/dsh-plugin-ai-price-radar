# AI 比价雷达

卡网 AI 订阅**只读比价**面板：把多个公开报价源聚合到一个本地面板里，搜索、筛选、直达原始购买链接。**本地运行、只读采集、不参与任何交易**。

![AI 比价雷达](icon.svg)

## 功能

- **全网报价搜索**：按关键词（如 `gpt`、`claude 质保`）在聚合报价里搜索。
- **四路筛选**：数据来源（可用源 / 全部）、库存口径（有货 / 缺货 / 全部含未知）、发卡平台（142 家：链动小铺 / 自建站 / 云猫寄售 / 独角数卡等）、商品交付类型（成品号 / 代充 / 卡密 / 车位等）。
- **统计栏**：主要报价数、来源标记数、当前结果最低价、数据源成功数。
- **报价卡片**：平台徽标、来源、商品标题、价格、店铺、观察时间，点击「查看原始报价」直达商家页面核对。
- **去重口径**：同一商品以「平台 + 店铺标识 + 商品标识 + 名称 + 价格」为键聚合，报价行不重复计数。
- **限流退避**：某源网关限流时该源冷却 10 分钟并如实标注，其余源不受影响。

## 隐私与边界

- 采集请求从**本机宿主进程**发出，不经过任何第三方服务器；结果只保存在内存缓存（默认 5 分钟 TTL）。
- 面板不写入会话日志，不影响模型上下文；不发送任何遥测。
- 所有价格与库存以商家页面为准；本面板只做信息聚合与导航。

## 榜单视图（v1.3.0）

面板顶部三个 Tab：**报价卡片 / 分类榜单 / 销售热榜**。

### 分类榜单

把七源的细分类目统一归入 12 个 AI 货架（ChatGPT、Claude、Gemini、Grok、Cursor、DeepSeek、邮箱账号、接码验证、API 中转、创作工具、其它订阅、其它 AI 服务）。每个货架展示：报价数、标记有货数、最低价、中位价、活跃店铺数、占全部报价的比例条、供给最多的店铺；点「查看该类报价」切回报价卡片并自动套用类目筛选。报价视图也新增第五个筛选器「商品类目」。

### 销售热榜

1. **店铺累计销量榜**：取自 AI价网公开「店铺销量」标签（约 450 家）与云猫寄售 `Shop/info` 的 `sell_count`，按店铺去重、冲突取较大值并标注来源。数字是商家自行公开的历史累计口径，非本插件成交数据。
2. **商品「已售」标记榜**：从商品标题解析「已售 16w+ / 已售 22000+」等标记，按降序展示。
3. **供给热度榜**：按店铺被收录的报价条数排序，明确标注「非销量」，用于发现铺货量大的店铺。

所有榜单均标注口径，付款前请回原站核对。

## 质量与性能（v1.4.0）

### 数据更全

- AI价网类目页从 8 个扩到 **38 个**（3 并发 + 200ms 间隔，遵守站点频率），报价从约 1,100 条增至约 3,600 条。
- 知途·拾价 catalog 从 400 商品扩到 **1,200 商品**，报价从约 1,200 条增至约 3,600 条。
- 云猫店铺发现页从 4 个扩到 12 个，公开店铺销量榜从 454 家增至 **788 家**。
- 合计去重后约 **2.1 万条报价**。

### 数据更准

- **同款比价 Tab**：按商家原始购买链接归并，1,126 款商品被 2 个以上来源收录；每个来源只取该链接最低价（避免同店不同规格误判），888 款存在真实跨源价差，合计可省约 ¥1.2 万。疑似引流价（¥1 以下对 ¥20 以上）单独排除并标注。报价卡片显示「N 源同款」标记。
- **来源状态真实化**：某源 0 条或报告故障时统计不再显示「全绿」，面板黄条给出具体原因（如云猫网关限流）。云猫 502/429 触发 10 分钟冷却并立即中止在途请求，不再空转。
- **ETag / 条件请求**：BiWu / PriceAI / AIFeeRadar 的 price-radar feed 带 `If-None-Match` / `If-Modified-Since`，304 复用缓存；`latest.json` 指针最多每分钟轮询一次（官方 API 约定）。

### 传输更快

- `/leida/api/offers` 在客户端支持 gzip 时自动压缩：实测 **10.86 MB → 1.98 MB**（约 18%）。
