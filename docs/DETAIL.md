# AI 比价雷达

卡网 AI 订阅**只读比价**面板：把多个公开报价源聚合到一个本地面板里，搜索、筛选、直达原始购买链接。**本地运行、只读采集、不参与任何交易**。

![AI 比价雷达](icon.svg)

## 功能

- **全网报价搜索**：按关键词（如 `gpt`、`claude 质保`）在聚合报价里搜索。
- **四路筛选**：数据来源（可用源 / 全部）、库存口径（有货 / 缺货 / 全部含未知）、发卡平台（142 家：链动小铺 / 自建站 / 云猫寄售 / 独角数卡等）、商品交付类型（成品号 / 代充 / 卡密 / 车位等）。
- **统计栏**：主要报价数、来源标记数、当前结果最低价、数据源成功数。
- **报价卡片**：平台徽标、来源、商品标题、价格、店铺、观察时间，点击「查看原始报价」直达商家页面核对。
- **去重口径**：同一商品以「平台 + 店铺标识 + 商品标识 + 名称 + 价格」为键聚合，报价行不重复计数。
- **限流退避**：某源网关限流时该源冷却 10 分钟并如实标注，其余源不受影响。

## 数据来源（七路聚合，2 万+ 报价）

| 来源 | 方式 | 说明 |
|---|---|---|
| BiWu.Ai（biwu.ai） | 官方只读快照 feed `/price-radar/latest.json` → 不可变快照 | 无需鉴权；官方 API 文档明确供 agent / 脚本读取；约 5 分钟一版 |
| PriceAI（priceai.cc） | price-radar.v1 官方快照 feed（同 BiWu 协议） | `/.well-known/price-radar.json` 发现，按其 API 约定带缓存拉取 |
| AIFeeRadar（aifeeradar.com） | price-radar.v1 官方快照 feed（同 BiWu 协议） | 同上 |
| AI价网（aiprice.club） | 解析公开类目页表格 | 数据遵循 CC BY 4.0（署名「AI价网 (http://aiprice.club)」） |
| 云猫寄售（catfk.com） | 公开店铺接口直连（`POST /shopApi/Shop/goodsList`，逐店实时抓取） | 店铺清单发现自 AI价网公开店铺目录；接口无需鉴权 |
| OpenPrice（openprice.cc） | 全量商品页内嵌公开数据（initialItems，1.8 万+ 条 / 344 店） | 站点 robots 全站开放 |
| 知途·拾价（price.yufu.pub） | 公开 catalog API（robots.txt 明确白名单 `/api/catalog`） | 1100+ 商品 3700+ 报价，含店铺评分与验价状态 |

**未接入**：水獭（shuifa.xyz，2026-11-13 起域名不可达）；链动小铺（wzyp.cn）直抓被其 ESA 人机验证拦截，但其报价由 BiWu / AI价网 / 知途 / OpenPrice 四路聚合覆盖；AIradar（airadar.vip）robots 明确禁止第三方批量采集，遵守之。

## 隐私与边界

- 采集请求从**本机宿主进程**发出，不经过任何第三方服务器；结果只保存在内存缓存（默认 5 分钟 TTL）。
- 面板不写入会话日志，不影响模型上下文；不发送任何遥测。
- 所有价格与库存以商家页面为准；本面板只做信息聚合与导航。
